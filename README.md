# Miki Miki

Відеоплеєр для Windows та Android на Flutter (libmpv через `media_kit`) з клієнтом [Hikka](https://hikka.io): каталог, списки, календар виходу, профіль, пошук відео в українських джерелах.

## Можливості
- Каталог, фільтри, сортування, календар виходу серій, статуси списків Hikka
- Плеєр на libmpv: субтитри, Anime4K, мініплеєр, жести на мобільному
- Продовження перегляду, кеш відповідей API (працює офлайн за наявності кешу)
- Українська локалізація та адаптивний інтерфейс (ПК + телефон)

## Збірка
Потрібен Flutter 3.x.
```
flutter pub get
flutter run -d windows
flutter build apk --release --target-platform android-arm64
```

## Безпека
- У репозиторії **немає** секретів: клієнтський секрет Hikka та ключ Moon зберігаються лише в Firebase Secret Manager і видаються застосунку через бекенд.
- Власні ключі (за потреби) вводяться в налаштуваннях застосунку і зберігаються локально.
- Знайшли вразливість — напишіть у Issues (без публікації ключів) або автору напряму.

## Застереження
Miki Miki **не хостить і не розповсюджує відео**. Застосунок лише знаходить посилання на сторонніх сайтах і програє їх. Відповідальність за вміст несуть власники цих сайтів. Застосунок не пов'язаний з Hikka.
